\section{Setup}

Single right-hand-side solve of the screened-Coulomb four-index integral on
the real graphene monolayer (Wannier $p_z$ orbital, $k_{323201}$), using the
production pipeline with the \texttt{PrecomputedVolumeField} (\texttt{cache\_fft})
volume-field method for the volume-potential stages. All timings are warm
(post-JIT), measured on a single idle node.

\section{Notes}

\begin{itemize}
\item \textbf{Dominant costs} are GMRES (\SI{22.2}{\second}), LHS assembly
      (\SI{13.6}{\second}), field construction (\SI{8.8}{\second}), and the
      interface build (\SI{6.8}{\second}); the pipeline is solve/assembly-bound.
\item \textbf{Amortization.} The RHS-independent precompute (field
      construction $+$ interface build $+$ LHS assembly $=\SI{29.1}{\second}$)
      is paid once. Each additional right-hand side on the same
      geometry/source family costs RHS $+$ GMRES $+$ eval $\approx
      \SI{30}{\second}$, dominated by GMRES.
\item \textbf{Volume field.} The precomputed spectral field is reused across
      all mesh-refinement depths and the evaluation; with \texttt{cache\_fft}
      the $u_{\mathrm{int}}$ read-out is interpolation-only
      (\SI{0.12}{\second}).
\item \textbf{Memory.} Peak RSS \SI{29.4}{\giga\byte}, set by the
      \texttt{cache\_fft} fine-grid storage; the standard field
      (\texttt{cache\_fft = false}) peaks at $\sim\SI{14}{\giga\byte}$ with
      $u_{\mathrm{int}}\approx\SI{0.4}{\second}$.
\end{itemize}

\section{Multiple right-hand sides}

The four-index matrix is assembled by solving many right-hand sides on
\emph{one} shared interface. We benchmark a central graphene $p_z$ orbital
together with its lattice neighbours (the \texttt{lattice\_scale} demo
convention): $K$ pair densities $\rho_{1j}=\phi_1\phi_j$ (on-site plus
neighbour shells out to a cutoff) are solved together as a batched
$n_d{=}K$ FMM operator with block GMRES, and the central row of the Coulomb
matrix, $V[\rho_{11},\rho_j]$, is evaluated on the fixed on-site target set.
The neighbour cutoff controls $K$. To run at the full 96 threads we use the
\textbf{ducc0 FFT backend} for FINUFFT: the stock FFTW build has a
$\sim$50$\times$ 96-thread plan pathology on these upsampled mode grids, which
cripples \emph{both} the interface build and the evaluation. Each cutoff runs
as its own Slurm-array task on a dedicated 96-core genoa node (2026-06-17).

\begin{itemize}
\item \textbf{Fixed setup amortizes.} Precompute (interface $+$ batched LHS,
      $\approx\SI{37}{\second}$) and the eval-side \texttt{pottrg} map build
      ($\approx\SI{58}{\second}$, the corrected layer-potential map over the
      fixed on-site target) are $K$-independent --- both are paid once per
      batch and spread over all $K$ right-hand sides. (The $K{=}4$
      \texttt{pottrg} value was confirmed against a slower-node outlier by a
      re-run on a normal node, \SI{55.6}{\second}.)
\item \textbf{Block solve is sublinear} in $K$ ($\sim K^{0.85}$): the batched
      $n_d{=}K$ FMM amortizes the tree build and near-field setup over the
      columns, so each added right-hand side is cheaper than the first
      (\SI{20.6}{\second} at $K{=}1$ vs.\ $\approx\SI{5.5}{\second}$ marginal
      at large $K$).
\item \textbf{Eval is linear} in $K$ ($\approx\SI{3.5}{\second}$ per pair): one
      TKM volume potential plus one corrected layer-potential apply per
      right-hand side, all on the same fixed on-site target set.
\item \textbf{Peak RAM grows linearly} ($\approx 18 + 7.5\,K$~GB), set by the
      block-GMRES $n_d{=}K$ FMM workspace; \SI{163}{\giga\byte} at $K{=}19$ on
      the \SI{1.5}{\tera\byte} node.
\item \textbf{ducc0 vs.\ FFTW.} Switching FINUFFT to the ducc0 FFT backend
      removes the FFTW 96-thread cliff (interface build at cutoff $2.5$:
      \SI{26}{\second} with ducc0 vs.\ \SI{171}{\second} with FFTW, both at 96
      threads), letting the whole pipeline run at full 96 threads.
      $u_{\mathrm{onsite}}\approx\SI{7.10}{\electronvolt}$ across $K$ (midplane
      orbital convention; cf.\ the \SI{9.88}{\electronvolt} single-RHS value
      above, which uses the top-face convention).
\end{itemize}

\section{Multiple right-hand sides on a heterojunction substrate (exp66)}

The same multi-RHS pipeline applied to a multi-dielectric \emph{heterojunction}
substrate: two $90\times90\times90$ cubes of different permittivity (Si/SiO$_2$,
$\varepsilon = 11.9\,|\,3.9$) sharing the buried internal face $x=c_x$, with a
$90\times90\times9$ slab ($\varepsilon=10$) on top, anchored on the central
graphene $p_z$ orbital (slab centre $=$ orbital centroid, junction directly
beneath); see Fig.~\ref{fig:mc_system}. The orbital plus its lattice neighbours
within a cutoff form $K$ pair densities $\rho_{1j}=\phi_1\phi_j$, block-solved on
one shared interface, and the central row $V[\rho_{11},\rho_{1j}]$ is evaluated.
The only pipeline change from the single-slab case above is \textbf{box-based
multi-region screening} (the interface spans three $\varepsilon$ regions, so the
single-region interface screening cannot be applied); 96 threads run via the
TKM3D in-function FINUFFT nthreads cap (no DUCC override needed here).

\begin{itemize}
\item \textbf{Onsite self-energy.} $V[\rho_{11},\rho_{11}]\approx 70.4$ (raw
      kernel units) against the bare interface-free value
      $V_{\mathrm{vac}}\approx 590$ --- the environment screens it
      $\approx 8.4\times$. $V[11]$ is $K$-independent to $\sim$0.2\% (it does not
      depend on the neighbours) and matches the single-RHS production value
      ($70.30$, $8.40\times$).
\item \textbf{Block solve dominates}, sublinear per RHS ($195\to57$~s/RHS);
      \textbf{eval is linear} ($\approx$5~s/pair); \textbf{precompute is
      $K$-independent} (interface $=$ \num{1.62}M points).
\item \textbf{\texttt{pottrg} is negligible} ($\approx\SI{0.2}{\second}$, vs.\
      $\approx\SI{55}{\second}$ for the graphene slab above): the thick slab
      keeps the orbital clear of the interface, so the target--panel neighbour
      list is \emph{empty} (0 hcubature corrections vs.\ 12{,}724 there) and the
      corrected layer-potential map collapses to its smooth FMM far field.
\item \textbf{Conditioning.} The high-contrast three-region junction needs
      30--36 block-GMRES iterations (vs.\ $\sim$8 for the single slab), and the
      $\sim$\num{1.6}M-point interface drives peak RAM to \SI{329}{\giga\byte} at
      $K{=}19$ ($\approx 16$~GB/$K$).
\end{itemize}

\section{Full lattice campaign: 10$\times$10 graphene on the heterojunction}

Production four-index run for the full \textbf{200-orbital} 10$\times$10 graphene
supercell on the exp66 multicube substrate (`lattice\_scale' campaign
\texttt{lattice\_10x10\_multicube}). The pairing cutoff (\SI{5.0}{} lattice units)
gives up to 30 neighbours per bulk centre (6 shells), tapering to 8 at the flake
corners, for \textbf{2611 distinct pair densities} $\rho_{ij}$ --- the basis of the
$2611\times2611$ Coulomb tensor $V_{ij,kl}$. Run as a single resumable job on
\textbf{10 genoa nodes} (one 96-core worker each; \texttt{solve}/\texttt{eval}
batches distributed via SlurmManager).

\begin{figure}[h]
\centering
\includegraphics[width=\textwidth]{../../../lattice_scale/figs/fig_V_ijkl_heatmap.pdf}
\caption{The four-index tensor $V_{ij,kl}$ (eV, orbital-normalized) for the
10$\times$10 lattice. Left: $\log_{10}|V|$ over the full $2611\times2611$ tensor
(pairs in campaign order); the bright diagonal is the pair self-interactions, and
off-diagonal couplings fall off 3--4 orders of magnitude. Right: the onsite element
$V_{iiii}$ (Hubbard $U_i$) as a surface over the orbital lattice, IDW-interpolated
from the 200 sites (black dots). $U_i$ ranges $2.18$ (bulk, maximally screened) to
\SI{2.59}{\electronvolt} (flake edge), and is lower over the high-$\varepsilon$ Si
half ($x<5.5$) than the SiO$_2$ half --- the heterojunction signature.}
\end{figure}

\begin{itemize}
\item \textbf{Eval is cheap because there are zero near-singular corrections.} The
      corrected layer-potential map over the \num{7.4}M-target cloud logged
      \emph{no} hcubature calculations in any of the 200 batches: the graphene
      orbital plane (targets at $z\approx7.5$, support $\approx[4.8,10.2]$) sits
      $\approx\SI{1.8}{}$ bohr clear of the slab faces ($z=3,12$), beyond the
      near-field range of the target-refined panels, so the map collapses to its
      smooth FMM far field. The README's feared eval blow-up does not occur with a
      thick host slab (cf.\ exp65's thin monolayer: $\sim$12{,}700 corrections).
\item \textbf{eV normalization.} $V_{ij,kl} = V^{\mathrm{raw}}\,4\pi E_2/(\lVert\phi_i\rVert
      \lVert\phi_j\rVert\lVert\phi_k\rVert\lVert\phi_l\rVert)$, $E_2=\SI{14.3996}{\electronvolt\angstrom}$,
      $\lVert\phi\rVert^2=\int\phi^2$ from the onsite pairs. (Normalizing by the
      per-pair density norm $\int\rho_{ij}$ instead --- the orbital overlap --- blows
      up off-diagonal elements, since it $\to0$ for distant pairs.)
\item \textbf{Quality.} Max relative asymmetry $|V-V^{\mathsf T}|/\max|V| = 5.1\%$,
      dominated by the low-overlap distant pairs (small, noisy $V$); the dominant
      onsite/near-neighbour elements are tighter. Tightening \texttt{edge\_refine\_level}
      ($2\to3$) / \texttt{n\_quad} would reduce it at higher solve cost.
\end{itemize}
