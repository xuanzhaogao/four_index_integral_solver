Write a JCP-style subsection describing a component-level numerical experiment that validates the truncated-kernel method (TKM) for free-space volume convolution with the Coulomb kernel.

Context:
In the solver, the incident potential generated by a smooth volume density is evaluated by the truncated-kernel method,

    u_inc(x) = (1 / 4 pi) int rho(y) / |x - y| dy,

or with an additional factor 1 / epsilon_m depending on the normalization. This component is used to evaluate the incident field and near-field volume contributions. The purpose of this experiment is to verify that TKM accurately evaluates the weakly singular Coulomb convolution, including target points inside the source support, and to validate the real-space padding condition used to avoid aliasing of the truncated kernel.

Test density:
Use a normalized three-dimensional Gaussian density

    rho(y) = 1 / (2 pi s^2)^{3/2} exp( - |y - y0|^2 / (2 s^2) ),

with y0 = 0 and a small width, for example s = 0.08 or s = 0.10. The density is sampled on a uniform grid in the box B = [-1,1]^3. Choose s small enough that the Gaussian tail outside B is below the smallest reported numerical error. State the estimated tail mass

    int_{R^3 \ B} rho(y) dy

or mention that it is negligible relative to the plotted errors.

Analytic reference:
Use the analytic full-space Coulomb potential of the Gaussian as the reference solution,

    u_ref(x)
    =
    (1 / 4 pi) erf( |x - y0| / (sqrt(2) s) ) / |x - y0|.

At x = y0, use the limiting value

    u_ref(y0)
    =
    (1 / 4 pi) sqrt(2 / pi) / s.

If the implementation uses the Coulomb kernel 1 / |x-y| rather than 1 / (4 pi |x-y|), remove the factor 1 / (4 pi) consistently from both TKM and the reference. If the dielectric normalization 1 / epsilon_m is included in the implementation, include the same factor in the reference.

Numerical setup:
Evaluate u_TKM on a target grid containing points inside the source support, including points near y0 where the Coulomb kernel is weakly singular. Use the same physical box and density for all tests. Unless testing aliasing, choose the real-space period P_alpha so that the truncated-kernel padding condition is satisfied:

    P_alpha >= l_alpha + L,

where l_alpha is the side length of the interaction box in direction alpha and

    L = sqrt(l_x^2 + l_y^2 + l_z^2).

Construct a 1 x 3 figure:

Panel (a): error slice.
Plot a two-dimensional slice, for example z = 0, of the absolute error

    log10 | u_TKM(x) - u_ref(x) |.

The target slice should pass through the Gaussian center y0. This panel demonstrates that the TKM accurately handles the weakly singular convolution even for target points inside the support of rho.

Panel (b): grid-convergence test.
With the padding condition satisfied, plot the relative L2 error

    E_u =
    || u_TKM - u_ref ||_{L2(Omega_chk)}
    /
    || u_ref ||_{L2(Omega_chk)}

as a function of the grid resolution n, for example n = 32, 48, 64, 96, 128. The check region Omega_chk may be the computational box or an interior subregion, but it should include the source support. The expected behavior is rapid convergence for the smooth Gaussian source until the error reaches the truncation, Fourier cutoff, interpolation, or floating-point floor.

Panel (c): aliasing / padding test.
Fix the grid resolution n and vary the real-space period or padding factor. Define

    eta = min_alpha P_alpha / (l_alpha + L).

Plot E_u as a function of eta. The expected behavior is that for eta < 1, periodic images of the truncated convolution contaminate the physical interaction region and the error is large. Once eta >= 1, the aliasing error is removed and the error enters a resolution-limited plateau. This panel directly validates the padding condition P_alpha >= l_alpha + L.

Important implementation details:
1. Keep the kernel normalization consistent between TKM and the analytic reference.
2. Make the Gaussian tail outside the finite computational box negligible compared with the plotted errors, or explicitly report the tail mass.
3. The reference is the analytic full-space Gaussian Coulomb potential, not direct summation and not FMM.
4. Panel (b) should vary grid resolution while keeping the padding condition satisfied.
5. Panel (c) should vary padding while keeping grid resolution fixed.
6. This experiment tests only the free-space volume convolution component and should not include dielectric interfaces or boundary integral solve errors.

Manuscript points to emphasize:
1. The Coulomb kernel is weakly singular when target points lie inside the support of rho, but the Gaussian convolution has a smooth analytic potential.
2. The agreement with the analytic Gaussian potential verifies the TKM volume solver independently of the BIE discretization.
3. The padding experiment demonstrates the practical necessity of the condition P_alpha >= l_alpha + L.
4. The use of a Gaussian source avoids reference-solution ambiguity and isolates the TKM error.

Suggested figure caption:
“Accuracy of the truncated-kernel volume solver for a Gaussian source. (a) Slice of log10 absolute error |u_TKM - u_ref| through the source center, showing accurate evaluation inside the support of the density. (b) Relative L2 error versus grid resolution with the padding condition satisfied. (c) Aliasing test: relative L2 error versus eta = min_alpha P_alpha / (l_alpha + L). The error is large when eta < 1 due to periodic-image contamination and reaches a resolution-limited plateau once eta >= 1.”
